# Сборка сервиса документов в .exe (Windows, PyInstaller)

Цель: менеджеры запускают сервис **кликом**, без установки Python. При старте поднимается
локальный сервер и сам открывается браузер на форме (`http://127.0.0.1:8077/form`).

Сборка **onedir** (папка с `.exe` + `_internal`). Данные (шаблоны, справочники, подписи, форма)
лежат **рядом с .exe** и правятся без пересборки.

---

## 1. Что нужно на машине сборки
- Python 3.10+ и зависимости проекта:
  ```bat
  pip install -r requirements.txt
  pip install pyinstaller
  ```

## 2. Сборка
Из папки проекта :
```bat
pyinstaller doc_generator.spec
```
Результат: **`dist\DocGenerator\`** — там `DocGenerator.exe` и папка `_internal\`.

## 3. Разложить папку для менеджера
Рядом с `DocGenerator.exe` (в `dist\DocGenerator\`) положить данные из проекта:
- скопировать **`input_dir\`** (шаблоны .docx/.xlsx, справочники .yaml, карту ЗНП);
- скопировать **`form.html`**;
- положить **`assets_private\`** с подписями и печатью (`podpis_ruk.png`, `podpis_buh.png`,
  `pechat.png`) — их нет в git, кладутся вручную.

Итоговая раскладка:
```
DocGenerator\
├─ DocGenerator.exe        ← запуск
├─ _internal\           ← библиотеки (НЕ трогать)
├─ form.html            ← копия из проекта
├─ input_dir\           ← шаблоны + справочники (правятся без пересборки)
├─ assets_private\      ← подписи и печать (вручную)
├─ output\              ← создастся сам: готовые пакеты по сделкам
├─ data\                ← создастся сам: счётчик номеров (nomera.json)
└─ input_dir\upload_znp\← создастся сам: загруженные файлы (заказ Альфа, спецификация)
```
Папки `output`, `data`, `upload_znp` создаются автоматически при первом запуске.

## 4. Запуск
- Двойной клик по **`DocGenerator.exe`** → откроется браузер с формой.
- Закрыть сервис: закрыть окно программы (в debug-сборке — окно консоли).
- **Запускать из обычной папки**: например `C:\DocGenerator\`.
  **НЕ из `Program Files`** — там нет прав на запись, и `output\ data\` не создадутся.

## 5. Консоль для отладки / без консоли для менеджеров
В файле **`doc_generator.spec`** вверху:
```python
DEBUG_CONSOLE = True    # есть консоль — видно ошибки (для отладки)
DEBUG_CONSOLE = False   # без консоли — чисто для менеджеров (финальная сборка)
```
Поменял → пересобрать (`pyinstaller doc_generator.spec`).
Совет: сначала собери с `True`, проверь, что всё работает и видно ошибки; финальную — с `False`.

---

## 6. Если не работает

**Антивирус ругается / удаляет .exe.**
Частая беда PyInstaller. Сборка `onedir` (как здесь) спокойнее, чем onefile; UPX выключен.
Добавь папку в исключения антивируса; в идеале — подпиши .exe сертификатом.

**`ModuleNotFoundError: <модуль>` при запуске.**
PyInstaller не подхватил динамический импорт. Добавь модуль в `hiddenimports` в `doc_generator.spec`
и пересобери. Кандидаты: что-то из `uvicorn`, `pydantic`, `PIL`, `multipart`. Запусти
debug-сборку (с консолью) — там видно точное имя.

**Форма пустая / «справочники не загружены» / нет шаблонов.**
Проверь, что рядом с .exe лежат `input_dir\`, `form.html`, `assets_private\`. Сервис ищет их
**рядом с .exe** (это правка `BASE_DIR`). При желании путь можно задать переменной окружения
`INPUT_DIR` / `OUTPUT_DIR` (как на Linux).

**`output` / `data` не создаются, ошибка прав.**
Запущено из `Program Files` или другой папки только для чтения. Перенеси в `C:\DocGenerator\`.

**Кириллица в пути капризничает.**
Если путь с кириллицей даёт сбои у загрузчика PyInstaller — запускай из папки с латинским
путём, например `C:\DocGenerator\`.

**Порт 8077 занят / второй клик.**
Программа не падает: если сервис уже запущен, она просто откроет форму уже работающего
экземпляра и сообщит об этом.

**PDF не нужен — LibreOffice не требуется.**
PDF выключен флагом `ENABLE_PDF=False` в `config.py`. Подпись и печать и так вшиты в `.docx`.
Если PDF понадобится — `ENABLE_PDF=True` и поставить LibreOffice на машины (в самой сборке
ничего менять не нужно).
