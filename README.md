# DocGenerator — сервис пакетов документов для перевозок

FastAPI-сервис для оптовой торговой компании (металлопрокат, закупка в РФ → доставка в РБ).
Менеджер заполняет одну веб-форму по рейсу, сервис собирает **пакет документов**:

- **заявка на транспортную перевозку** (`.docx`) — всегда;
- **доверенность М-2** (`.docx`) — всем поставщикам, кроме тех, кто работает по своему бланку заказа;
- **ЗНП — «Заказ на поставку»** (`.xlsx/.xlsm`) — заполнение *чужого* Excel-бланка поставщика по «карте полей»;
- **гарантийное письмо** (`.docx`) — для поставщиков, которые его требуют.

Состав пакета определяется справочником поставщиков (`skladskoy_dokument`), а не кодом.

> **Все данные в репозитории вымышленные**: компания «Ромашка», поставщики «Альфа/Бета/Гамма/Дельта»,
> водители, телефоны, реквизиты (`BY00TEST…`, `УНП 100 000 001`). Реальные шаблоны и справочники
> заказчика в репозиторий не входят.

## Возможности
- кастомная форма (`/form`): зависимые списки, условные блоки по поставщику, 1–2 точки выгрузки;
- разбор текста перевозчика («Авто: … Водитель: … Паспорт: …») в поля формы — `/parse_voditel`;
- авто-нумерация исходящих `ДДММ/N` и сквозной счётчик доверенностей;
- количество ТМЦ прописью (`num2words`);
- заполнение Excel-бланка поставщика **без меток в файле**: ячейка ищется по подписи в колонке A
  и жёлтой заливке, поэтому работает, даже если число строк продукции в заказе «плавает»;
- подпись и печать накладываются плавающими картинками поверх линий подписи (по галочке в форме);
- загрузка файла заказа и спецификации через форму, скачивание пакета одним ZIP;
- защита от обхода путей при скачивании и при сохранении загруженных файлов;
- сборка в `.exe` (PyInstaller) для запуска менеджерами без Python;
- опционально — PDF через LibreOffice и интеграция с n8n (webhook).

## Стек
Python 3.10+, FastAPI, Pydantic v2, docxtpl / python-docx, openpyxl, PyYAML, PyInstaller.

## Структура
```
config.py        пути, константы, значения по умолчанию
schemas.py       модели запроса (pydantic)
references.py    загрузка справочников (YAML)
validators.py    мягкая валидация -> предупреждения
parser.py        разбор текста водителя
numbering.py     исходящие номера ДДММ/N
propis.py        числа прописью
context.py       сборка контекста для шаблонов
generators.py    docxtpl / openpyxl / LibreOffice (PDF)
main.py          FastAPI: /, /form, /spravochniki, /generate, /upload_znp, /upload_spec,
                 /parse_voditel, /next_nomer, /files/..., /zip/...
form.html        веб-форма
test_trips.py    сквозной тест на двух поездках + негативные случаи
input_dir/       демо-шаблоны (.docx, бланк ЗНП .xlsx), справочники (.yaml), карта полей ЗНП
n8n/             workflow для n8n (необязательно)
DEPLOY_LINUX.md  запуск на сервере
СБОРКА_EXE.md    сборка .exe для Windows
```

## Быстрый старт
```bash
python -m venv .venv
.venv\Scripts\activate            # Linux: source .venv/bin/activate
pip install -r requirements.txt
python config.py                  # проверка: все шаблоны и справочники на месте
python test_trips.py              # сквозной тест
python main.py                    # http://127.0.0.1:8077/form
```

Подпись и печать в репозиторий не входят: чтобы проверить наложение, положите любые PNG
в папку `assets_private/` (`podpis_ruk.png`, `podpis_buh.png`, `pechat.png`).

## Не в репозитории
`output/`, `uploads/`, `input_dir/upload_znp/`, `data/`, `assets_private/`, `.venv/`, `build/`, `dist/` — см. `.gitignore`.
