# Перенос сервиса документов на Linux

> **n8n больше не нужен.** Форма (`/form`) отправляет данные **напрямую** в сервис (`/generate`)
> и сразу показывает готовый пакет со ссылками на скачивание. Для запуска достаточно разделов
> **1–5**. Разделы 6–9 (про n8n) — **устаревшие**, оставлены только для справки.

## 1. Что скопировать на Linux
- весь каталог с кодом (`config.py, schemas.py, references.py, validators.py, context.py,
  generators.py, main.py, requirements.txt, run_linux.sh`);
- папку с шаблонами/справочниками (содержимое вашего `input_dir`) — в место, которое
  укажете в `INPUT_DIR` (пример: `/opt/docgen/input_dir`);
- файлы заказов Альфа (`.xlsm`), которые приходят на конкретные поездки — путь к ним
  передаётся в запросе полем `znp_file` (для ветки Альфа).

## 2. Что установить
```bash
sudo apt-get update
sudo apt-get install -y python3 python3-venv python3-pip
# LibreOffice — ТОЛЬКО если нужен PDF (pdf=true); без него сервис работает, PDF пропускается:
sudo apt-get install -y libreoffice

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## 3. Переменные окружения (пути не прошиты под Windows)
```bash
export INPUT_DIR=/opt/docgen/input_dir     # шаблоны + справочники
export OUTPUT_DIR=/opt/docgen/output       # готовые документы
```
(если не задать — `OUTPUT_DIR` по умолчанию `./output` рядом с кодом; `INPUT_DIR` задать обязательно).

## 4. Запуск сервиса
```bash
bash run_linux.sh
# равнозначно:
uvicorn main:app --host 0.0.0.0 --port 8077
```
- **`--host 0.0.0.0` обязателен** — иначе n8n из Docker не достучится (см. п.6).
- Проверка путей до запуска: `python config.py` → все строки должны быть `OK`.
- Чтобы держался после выхода из SSH — `nohup bash run_linux.sh &`, либо `screen`/`tmux`,
  либо завести systemd-сервис.

## 5. Проверить сервис АВТОНОМНО (без n8n)
```bash

```
Открыть в браузере (если есть доступ к хосту): `http://<IP-хоста>:8077/docs` — Swagger.

## 6. Стыковка с n8n (Docker на том же Linux)
- В HTTP-нодах адрес: `http://host.docker.internal:8077/generate` (порт = порт сервиса, 8077).
- **На Linux `host.docker.internal` сам не работает** — контейнер n8n надо запустить с маппингом
  на хост-шлюз:
  - docker run: `--add-host=host.docker.internal:host-gateway`
  - docker-compose:
    ```yaml
    services:
      n8n:
        extra_hosts:
          - "host.docker.internal:host-gateway"
    ```
  (альтернатива — указывать IP docker-моста хоста, обычно `172.17.0.1`).
- Проверка из контейнера: `docker exec -it <n8n> sh -c "wget -qO- http://host.docker.internal:8077/"`
  должно вернуть JSON health.

## 7. Импорт workflow в n8n (необязательно)
Актуальный workflow — **`n8n/zadacha_C_workflow_v7.json`** (кастомная форма + webhook, см. п.9).
- n8n → Workflows → **Import from File** → `zadacha_C_workflow_v7.json`.
- В HTTP-ноде проверьте URL: `http://host.docker.internal:8077/generate`.

## 8. Сквозной тест (Альфа и Бета)
Сервис запущен (п.4), n8n его видит (п.6). Открыть форму и заполнить:

**Альфа → заявка + доверенность + ЗНП:**
- Поставщик: `Альфа`; Склад погрузки: `Из справочника (город ниже)`; Склад — город: `Северный`
- Перевозчик, Исх. № заявки, Дата загрузки, водитель/паспорт/авто
- Файл заказа Альфа (путь): полный путь к присланному `.xlsm` на Linux-хосте
- Дата отгрузки / Время приезда (для ЗНП); Выгрузка 1 — получатель/адрес/контакт
- → 3 файла в `OUTPUT_DIR`: `zayavka…docx`, `doverennost…docx`, `znp…xlsm`

**Бета → заявка + доверенность + письмо:**
- Поставщик: `Бета`; Склад — город: `Заречный` (или `Заречный, Лесной`)
- Приложение 1 — № и дата (для письма); Выгрузка — `ООО «Стройпарк»` (адрес подтянет справочник)
- → 3 файла: заявка, доверенность, письмо

**Ручной поставщик/склад** (нет в справочнике): Поставщик → `Другой` (+название/№ договора),
Склад → `Другой склад` (+название/адрес/контакт) → пакет заявка + доверенность.

> Цепочка «форма → нода → сервис» уже проверена локально на реальном JS-коде ноды (Node) для Альфа и Бета —
> пакеты корректные. На Linux останется прогнать через саму форму n8n.

### Последняя миля (на заметку)
Сервис возвращает **пути** к файлам (в `OUTPUT_DIR`), а не сами файлы. Чтобы менеджер получал
документы прямо из формы (вложением/ссылкой), позже добавьте в workflow шаг чтения файлов из
`OUTPUT_DIR` (общий с n8n путь) или отдачу файлов сервисом. Для теста достаточно, что файлы
появляются в `OUTPUT_DIR`.

## 9. Кастомная форма + webhook (v7) — рекомендуемый поток
Вместо встроенной формы n8n — своя форма из сервиса. Поток:
**форма (GET /form) → POST TripRequest на webhook n8n → n8n → /generate → ответ форме.**

Документы складываются в `OUTPUT_DIR/{Исх№}_{дата-время}/` — отдельная папка на каждую поездку.

**Настройка:**
1. Импортируйте **`zadacha_C_workflow_v7.json`** в n8n → нода **Webhook: данные формы**:
   - **Activate** → скопируйте **Production URL** (вид `http://<host>:5678/webhook/zadacha-c`);
   - в **Options → Allowed Origins (CORS)** поставьте `*` (или адрес формы `http://<host>:8077`),
     иначе браузер не примет ответ (форма и webhook — разные порты = разный origin).
2. Запустите сервис, передав адрес webhook (форма его подставит):
   ```bash
   export N8N_WEBHOOK_URL="http://<host>:5678/webhook/zadacha-c"
   export INPUT_DIR=/opt/docgen/input_dir
   bash run_linux.sh
   ```
3. Откройте форму: **http://<host>:8077/form** — списки подтянутся из `/spravochniki`.

**Сквозной тест (через браузер):**
- **Альфа:** Поставщик `Альфа` → склад `Северный`; водитель, Исх.№, **путь к файлу заказа .xlsm**,
  дата отгрузки/время; выгрузка → пакет **заявка + доверенность + ЗНП**.
- **Бета:** Поставщик `Бета` → склад `Заречный`; приложение №/дата; выгрузка → **заявка + доверенность + письмо**.
- **Прочий (Гамма):** Поставщик `Гамма` → склад `Южный`; выгрузка → **заявка + доверенность**.
- **Ручной:** Поставщик `Другой` (+название/договор); Склад `Другой склад` (+адрес/контакт) → заявка + доверенность.
- После «Сформировать пакет» форма покажет состав пакета и **папку сеанса**; файлы — в `OUTPUT_DIR/<папка>`.

> Цепочка «форма (buildTrip) → сервис» проверена локально на реальном JS формы (Node) для Альфа, Бета, Гамма и
> ручного ввода — пакеты и папки корректные. На Linux останется поднять webhook и прогнать через браузер.
